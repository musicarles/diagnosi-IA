# Diagnosi IA - Centre Educatiu

Eina web per a centres educatius per autoavaluar l'ús de la IA mitjançant un qüestionari de 40 preguntes.

## Funcionalitats

- **Diagnosi**: 40 preguntes en 6 àmbits (Pràctica docent, Ús de l'alumnat, Transformació pedagògica, Avaluació, Ètica i privacitat, Organització del centre) amb respostes SÍ / NO / NO APLICA
- **Anàlisi de millora**: Per a cada resposta "NO", es poden definir prioritat, assolibilitat, dificultat i proposta de millora
- **Exportació**: Genera informes en CSV i PDF (amb portada, resum, detall per àmbits, anàlisi de millora i full de canvis)
- **Full de canvis**: Registre d'edicions amb versió, data, descripció i persona responsable
- **Local**: Totes les dades es guarden al navegador (localStorage)

## Tecnologies

- HTML / CSS / JavaScript pur (sense frameworks)
- jsPDF + autoTable per a la generació de PDF
- localStorage per a la persistència de dades
